# 检索与证据政策

本文件是六看、拆解、适配度各阶段**检索与证据质量**的唯一执行依据。子 Agent 任务书必须携带本文件的要点，因为子 Agent 看不到主会话的记忆文件。

## 检索通道现状

| 通道 | 状态 | 说明 |
| --- | --- | --- |
| `web_search`（searxng） | **不可用** | 已知返回 0 结果，不要反复重试 |
| Bing 搜索 | 有限可用 | 中文分词差（如"吧唧"会被拆碎），仅作补充 |
| 搜狗 | 不可用 | 触发验证码 |
| `web_fetch` + `https://so.com/s?q=<关键词>` | **可用** | 首选替代通道 |
| `web_fetch` + `https://cn.bing.com/search?q=<关键词>` | **可用** | 备选通道 |

## 检索通道轻量检查

六看启动前，如需确认检索通道可用，只做通道检查，不搜集产品、市场、竞品或政策证据。

- 只检查本文件中标记为可用的通道；`web_search`（searxng）已知不可用，不得用它探测或反复重试。
- 首选通道最多做一次轻量探测；失败时最多再尝试一次已记录的备用通道。
- 探测通过后立即启动六看子 Agent；探测失败且备用通道也不可用时，停止六看并向用户说明原因。

## 证据分级

| 等级 | 定义 |
| --- | --- |
| A | 官方或一手来源：官网、公告、平台原始页面、法规原文 |
| B | 可靠二手：主流媒体、行业研报、平台榜单 |
| C | 社区与推测：UGC、论坛、未署名转载、模型推断 |

规则：

- **结论只能由 A / B 级证据支撑**；C 级只能作为线索，必须标注 UNKNOWN 或转为补证任务。
- 证据项必须带 `fact`、`source`、ISO 格式 `date`、`grade`、`signal`（正向/反向）五个字段。用于 YES/S51 的关键维度证据还须带 `dimension` 和 `corroborating_sources`。
- 缺证时保守处理，不得用推测补齐事实。

## 双源验证

- B 级及以上证据必须有 **≥2 个相互独立的来源**，否则降级为 C。
- 关键事实（市场规模、价格带、融资、政策条文、BOM 成本）一律双源核对。
- 来源冲突时标记冲突，不得静默择一。

## 复评触发

市场、价格、融资、竞品类证据的**有效期按 6 个月**计；政策类按 12 个月。超期证据在复用前必须复评，并保留版本原因。

## 与记忆文件的关系

检索产生的证据**只能写入证据台账**（`runtime/evidence_ledger/`），不得只留在 `MEMORY.md` 或每日记忆里。原因：记忆文件按设计只在主会话加载，子 Agent 读不到，会导致同一标的被反复从头检索。
脚本对 YES 检查六维结论齐备，并对 market/user/competitor 的 A/B 正向证据检查日期与两个不同来源标识；S51 对 org_capability/quick_launch/business_path 做同类检查。不同来源的实际独立性、真实性和事实冲突仍须人工核验，字符串不同并不能证明独立。
