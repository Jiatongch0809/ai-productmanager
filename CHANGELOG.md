# Changelog

## v1.0.0 (2026-10-21)

Initial public release.

- Workflow A: opportunity evaluation with six-lens scan, 8-dimension fit model, and S51–S54 gates.
- Workflow B: demand insight, business plan, PRD, HITL gate, and prototype demo.
- Evidence ledger with grading, double-sourcing, freshness rules, and version history.
- Sharded sub-agent execution with checkpoint/resume.
- Deterministic CLI: ledger, task, gate, state, and report commands.
- Idempotent `pending_output` delivery with pending/sending/sent states.
- 49 regression tests covering scoring, gates, sharding, end-to-end branches, and report guards.
