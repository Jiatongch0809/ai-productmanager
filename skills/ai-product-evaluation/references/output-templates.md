# 三件套输出结构模板（md / docx / pptx）

## 生成顺序

1. 先写 Markdown 主稿，作为含全部证据与来源的内容基准。
2. 用 python-docx 生成 Word：逐章节映射 Markdown，标题用 Heading 1/2，证据与评分用表格。
3. 用 python-pptx 生成 16:9 PPT：提炼要点，每页一个主题。
4. 验证三个文件均存在且大小正常。

## Word 要点

- 文档属性：标题、作者（AI 产品评估）。
- 封面：报告名称、类型、日期、评估框架。
- 执行摘要含总分、等级、建议动作、最大不确定性。
- 六看按维度列出信号、证据、结论与待验证项。
- 证据、评分、风险用表格；结尾标注 AI 初稿、最终 Go/No Go 须经 Gate 会确认。
- 中文字体建议微软雅黑。

## PPT 规范

- 16:9，13.333 x 7.5 英寸；Microsoft YaHei。
- 深蓝 #1B2A4A 主色，蓝 #2E86DE 强调，红 #C0392B 表示 No Go，绿 #1E8E5A 表示 Go，橙 #E67E22 表示观察。
- 约 10 页：封面、执行摘要、六看上/下、证据分级、AI 价值、八维评分、3-7-30、Gate 与风险、结论与下一步。
- 每页文字精炼，优先卡片与表格。

## 一致性检查

- 总分、等级、结论一致。
- 证据等级一致。
- 评分口径一致。
- 同名不同后缀，符合会话文件输出路径。
