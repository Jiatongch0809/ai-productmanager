# 产品机会扫描提速快车道

## 适用范围
用于“产品情报拆解 → 六看机会扫描 → 组织适配度”的连续任务。快车道优化等待和重复检索，但不绕过证据、Gate 或产物门禁。

## 默认产物
- 六看：Markdown 摘要 + T-A02 XLSX；
- 适配度：Markdown/DOCX 决策卡 + T-A04 XLSX；
- 完整评估：Markdown + DOCX + 原生可编辑 PPTX，必要时附证据 XLSX；
- 产品机会一页卡：Markdown/DOCX 可编辑底稿；仅用户明确要求视觉卡时，额外生成单张 PNG。

不得把 PNG 作为六看、适配度或完整评估的默认产物；不得用图片替代正式底稿。

## 任务路由前置
开始前锁定：当前阶段、Opportunity ID、机会定义、用户/场景/问题、证据状态、Gate、目标产物、是否明确授权生成一页卡视觉 PNG。

输入分流：
- 一批新品/众筹/前沿信号 → 先走机会漏斗，完成 A/B/C 分流后停止，等用户选择；
- 明确单品 → 走单品拆解；只有用户表达“按机制跑/完整评估”等完整意图时，才按 Gate 继续；
- 已明确用户、场景、问题的机会 → 可直接进入六看；
- 仅要求某种文件 → 只生成对应适配产物，不强行跑完整机会链路。

## 单一事实台账
第一轮建立结构化字段：身份、状态、价格、用户、场景、规格、性能、安全、销量、竞品、来源、日期、证据等级、事实/判断/未知、验证状态。后续 Markdown、DOCX、PPTX、XLSX 和一页卡均从同一台账生成。

## 并行与非阻塞
独立来源并行检索；补证任务不阻塞主链路骨架，但未回来的内容必须标注 UNKNOWN/待验证，不得写成事实。后台补证只能更新证据台账和版本，不得静默改变 Gate 结论。

## Gate 规则
- 六看：YES 才能交适配度；CONDITIONAL 先生成 Evidence Task；WATCH/NO 停止。
- 适配度：按统一八维评分规则执行；高适配才进入创新评审，中适配补证，低适配观察或暂停。
- 任何阶段不得自动进入 PRD、Demo、MVP、BOM、开发、量产或立项，除非用户明确授权。

## 一页卡视觉边界
一页卡 PNG 是唯一允许 image 的场景。生成前必须锁定：机会一句话、当前结论、六看速览、最多 3 条正向信号、最多 3 条反向信号、最多 3 个最大未知、Gate 和 1–3 条下一步动作。单次生成单张，失败时回到提示词/版式修订，不扩展为多图调用。

## 产物门禁
核验文件存在、非空、可打开、与事实台账和 Gate 一致。PPT 必须为原生可编辑内容；Word/DOCX 和 XLSX 字段完整；一页卡 PNG 若生成，需与可编辑底稿逐项核对。
