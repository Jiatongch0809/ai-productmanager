# 组织适配度评估

## 触发
六看 YES，或 CONDITIONAL 的关键阻断已补齐；或已有充分外部事实且只需判断是否适合本组织。六看 NO/WATCH、机会模糊、外部事实不足或评分大量靠猜时不启动。

## 原则
六看判断外部机会是否成立；本 Skill 判断是否适合本组织。继承外部事实，不重复完整六看；外部事实与组织内部事实分开；先证据后评分；缺证保守评分；高适配不等于立项。

## 八维固定模型（100 分）
市场/趋势确定性10；用户需求强度15；品类/竞品验证10；AI价值必要性10；组织能力匹配25；快速落地可行性15；商业转化路径10；成本与风险可控性5。八项必须全部完成整数评分，权重不得修改。

## 统一 Gate
- 80–100：高适配 / S51，形成适配度输出包并提交创新评审；
- 65–79：中适配 / S52，形成补证任务包后复评；
- 50–64：低适配 / S53，进入观察池，不投入开发；
- 0–49：不适配 / S54，暂停并记录重启条件。

总分低于 60 时，另标注“未达到完整评估概念成案初筛线”；60–64 仍按 S53 处理，不得表述为有条件 Go。

## 输出与停止
首屏展示总分、等级、评分状态、当前建议、三项核心优势、三项关键缺口和下一步验证重点；再给八维明细、证据、评分说明、风险/待补项、决策建议。标注“GPT初评｜待内部跨角色校准”（如适用）。默认输出 Markdown/DOCX + T-A04 XLSX；按需原生可编辑 PPTX，不调用生图。完成后停止，不自动执行 Demo、MVP、PRD、BOM、开发、量产或立项。

## 交接/复评
高适配交给 AI 创新评审；中适配交补证复评；低/不适配进入观察或暂停。新客户需求/订单/试点、技术/Demo、BOM/成本、供应链、竞品/政策或内部资源变化时增量复评并保留版本原因。发现外部事实不足时，生成 Evidence Gap Return Package 返回六看。
